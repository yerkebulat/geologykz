# Source rights and provenance

Scan-derived tiles of K-41-Б Gory Bukuntau, geological map, Kazakh SSR series, 1:500,000, 1979. Source: Extra collection (shared scans) of Soviet geological maps (file `К-41-Б-gory-bukuntau-geologicheskaya-karta-kazahskoy-ssr.jpg`).

Rights remain with the original authors or rightsholders. Shared with this project as a teaching collection; no open license established. These scan-derived tiles are not covered by the repository code license. Original scans are not committed. `georef.json` records the corner control points, the fit and the source hash.
