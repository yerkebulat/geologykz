## Website (GitHub Pages)

Plain static files in `/docs` (no build step), live at https://yerkebulat.github.io/geologykz/

- MapLibre GL JS map with Zhezkazgan and Mangistau lithology GeoJSON
- Layer toggles, opacity, popups, geolocate, Esri satellite basemap
- Legends generated from `data/legends.json` (unique MAP_CODE + colour)
- Data credit: Orr and Associates (2006)

GitHub Pages: Settings → Pages → Deploy from branch `main` / folder `/docs`.
