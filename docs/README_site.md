## Website (GitHub Pages)

Plain static files in `/docs` (no build step), live at https://kzgeology.com

- MapLibre GL JS map with Macrostrat geologic units clipped to Kazakhstan
- Layer toggles, opacity, popups, geolocate, Esri satellite basemap
- Legend built in the browser from the units in `data/kazakhstan_macrostrat.geojson`
- Data credit: Geologic map data © Macrostrat (macrostrat.org), CC-BY 4.0. Sources: Chorlton, L.B. 2007, Generalized Geology of the World, GSC Open File 5529, doi:10.4095/223767; Asch, K. 2003, IGME 5000 International Geological Map of Europe 1:5M, BGR. Clipped to Kazakhstan and simplified.

GitHub Pages: Settings → Pages → Deploy from branch `main` / folder `/docs`.
