# geologykz

Open geological map of Kazakhstan: interactive MapLibre showcase with Macrostrat geologic map data clipped to Kazakhstan.

Live: https://yerkebulat.github.io/geologykz/

## Attribution

Geologic map data © Macrostrat (macrostrat.org), CC-BY 4.0. Sources: Chorlton, L.B. 2007, Generalized Geology of the World, GSC Open File 5529, doi:10.4095/223767; Asch, K. 2003, IGME 5000 International Geological Map of Europe 1:5M, BGR. Clipped to Kazakhstan and simplified.
