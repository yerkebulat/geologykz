# geologykz

Open geological map of Kazakhstan: interactive MapLibre showcase with Macrostrat geologic map data clipped to Kazakhstan.

Live: https://kzgeology.com

## Attribution

Geologic map data © Macrostrat (macrostrat.org), CC-BY 4.0. Sources: Chorlton, L.B. 2007, Generalized Geology of the World, GSC Open File 5529, doi:10.4095/223767; Asch, K. 2003, IGME 5000 International Geological Map of Europe 1:5M, BGR. Clipped to Kazakhstan and simplified.

## Experimental detailed geological sheet

The optional **Detailed maps / 1:200,000 M-43-XXXI** layer offers Scan and approximate Colors modes. It is off by default and lazily loaded. [Processing notes](tools/detailed-maps/README.md) record provisional georeferencing and classification limits. [Source rights and notices](docs/data/detailed/m43xxxi/RIGHTS.md) apply separately to these scan-derived assets: no open-license or public-domain status is asserted, and no software license grants rights to the underlying map.
